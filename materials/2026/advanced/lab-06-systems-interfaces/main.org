#+end_src

Requirements:

1. ~to_c_bytes~ returns the UTF-8 bytes of ~input~ followed by one NUL byte.
2. ~to_c_bytes~ rejects interior NUL bytes and reports their byte index.
3. ~strlen_checked~ returns the number of bytes before the first NUL byte.
4. ~strlen_checked~ must reject an unterminated slice before calling C.
5. ~split_c_string_block~ parses consecutive NUL-terminated UTF-8 strings.
6. Empty strings inside the block are valid.
7. A non-empty block must end with NUL.
8. Invalid UTF-8 in a string returns ~InvalidUtf8~.

Suggested checks:

#+begin_src rust

assert_eq!(to_c_bytes("a\0b"), Err(CStringError::InteriorNul(1)));
assert_eq!(strlen_checked(b"abc\0ignored").unwrap(), 3);
assert_eq!(strlen_checked(b"abc"), Err(CStringError::MissingTerminator));
assert_eq!(split_c_string_block(b"red\0\0blue\0").unwrap(), vec!["red", "", "blue"]);
#+end_src

Requirements:

#+begin_src rust

assert_eq!(mapping.len(), 16);
mapping.fill(0xAB);
assert_eq!(mapping.as_slice(), &[0xAB; 16]);
mapping.as_mut_slice()[3] = 7;
assert_eq!(mapping.as_slice()[3], 7);
assert_eq!(Mapping::anonymous(0).unwrap_err().kind(), std::io::ErrorKind::InvalidInput);

* Exercise 3: Pinned Self-Referential Record

Implement a small address-sensitive type. The object owns a ~String~ and stores a

    }

    pub fn pointer_matches(self: Pin<&Self>) -> bool {
        todo!()
    }

    pub fn rename(self: Pin<&mut Self>, name: String) {
        todo!()

#+end_src

Requirements:

1. ~StableRecord~ must not implement ~Unpin~ automatically.
2. ~new~ returns ~Pin<Box<StableRecord>>~.
3. Initialize ~name_ptr~ only after the value is pinned in the box.
4. ~pointer_matches~ checks whether ~name_ptr~ points to the current ~name~ field.
5. ~rename~ may replace the string value, but must keep the internal pointer valid.
6. Do not expose ~&mut StableRecord~ through the public API.

Suggested checks:

#+begin_src rust
let mut record = StableRecord::new("alpha".to_string());
assert_eq!(record.as_ref().name(), "alpha");
assert!(record.as_ref().pointer_matches());
record.as_mut().rename("beta".to_string());
assert_eq!(record.as_ref().name(), "beta");
assert!(record.as_ref().pointer_matches());

let moved_pin = record;
assert_eq!(moved_pin.as_ref().name(), "beta");
assert!(moved_pin.as_ref().pointer_matches());
#+end_src
